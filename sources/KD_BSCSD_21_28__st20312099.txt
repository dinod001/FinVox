2. Introduction 
 
Small and Medium Enterprises (SMEs) are at the heart of the Sri Lankan economy and make 
up more than 75% of all registered businesses in the country, providing around 45% of total 
employment (IFC, 2026). Despite their pivotal economic role, the majority of SME owners run 
their businesses without expert financial counseling, relying solely on their intuition, 
calculations, or advice from their business associates when dealing with money management 
issues, investments, and credit arrangements (Thathsarani, 2023). 
The implications of this issue are disastrous. As research demonstrates, poor management of 
finances is the key factor in the downfall of many businesses, with as much as 80% of SMEs 
being shut down within the first few years (Herath, 2026) . A separate study by Nations Trust 
Bank confirmed that 75% of SMEs close down within seven years, with financial inadequacy 
cited as a primary driver  (Jayathilake, 2018). The cost of hiring an expert CFO or financial 
counselor would be somewhere between LKR 50,000 and LKR 200,000 per month, which is 
too high for the majority of small business owners. 
The proposed AI-powered solution in this project is a SME Financial Advisory system that 
works by enabling a SME owner to upload their financial data (Excel/CSV format, invoices 
and bank statements) and communicating with an AI system using natural language to provide 
personalized insights into cash flow management, budget management, investment analysis, 
and financial health assessment. 
This AI-powered advisory system will offer a more sophisticated approach to SME owners 
than the existing accounting software tools such as QuickBooks, Xero, and Zoho Books since 
it enables users to make informed decisions based on their financial data as o pposed to being 
used for mere accounting purposes. Furthermore, having a voice assistant enables any user to 
interact with the system without needing to know how to operate traditional software 
applications. (Broby, 2022)

the programme:

in this project have been studied.

3. Current Situation Leading to Problem Identification 
 
 
3.1 The SME Financial Management Crisis in Sri Lanka 
The economic problems encountered in Sri Lanka in 2022, where there were inflation rates of 
more than 70% as well as a shortage of foreign currency, and the country had its first sovereign 
debt default  (lanka, 2022) , brought about a number of challenges within the operations of 
SMEs. The firms which did not adequately plan their cash flows and were not properly invested 
found themselves in difficult situations as most of them were collapsing because of poor 
management practices in finance (IFC, 2026). 
The World Bank confirmed that approximately 68% of Sri Lankan SMEs struggle with access 
to finance as a core operational challenge (worldbank, 2023), while research by (Thathsarani, 
2023)found that 65% of SMEs in Sri Lanka face significant difficulties in accessing credit from 
the formal financial sector one of the highest rates in South Asia (Thathsarani, 2023) 
 
It is apparent from the above discussion that there is an urgent need for financial advice in Sri 
Lanka. The problem facing the SME owners now is how to access such services.

3.4 The Voice Interface Gap

design. Many SME owners in Sri Lanka especially those in the retail, manufacturing, and

ask for a solution. For example, there is no application that would allow the owner to ask, "Can 
I afford to hire two more employees next month?" Such a feature i s what makes our system

4. Proposed Technique to Solve the Current Problem 
 
 
4.1 Architectural Overview 
 
This solution consists of three interacting technology layers that contribute to an intelligent 
financial adviser which engages in conversations with users: 
• V oice Agent Layer: Speech to Text and Text to Speech pipelines that allow SME 
owners to communicate with the system not only through text but also through 
verbal speech 
• Multi-Agent AI Core: Consists of five specialized AI agents responsible for 
different financial areas controlled by a centralized Orchestrator Agent designed 
with the help of the LangGraph framework 
• Data Intelligence Layer: Retrieval Augmented Generation (RAG) pipeline for 
processing uploaded Excel/CSV files and extracting relevant financial information 
4.2 Voice Agent Design 
V oice agent is one of the most significant features of the current project. It allows users, who 
own small and medium -sized enterprises, to operate the system using only their voice,

eliminating issues with literacy and familiarity with technology. The voice module works in

1. The user asks a financial question in English via the web application interface.

4.4 RAG Pipeline for Financial Data 
When the SME owner submits a file such as an Excel or CSV spreadsheet (for example, the 
monthly P&L report, the bank statement, the cost of inventory), the Document Parser Agent 
runs the file through this pipeline: 
1. The file is parsed using Pandas (CSV/Excel) or tabula-py (PDF tables), resulting 
in structured rows and columns of data 
2. The parsed data is broken down into semantically sensible chunks (monthly totals, 
breakdown per category, specific transactions) 
Project Proposal | AI-Powered SME Financial Advisory System with Voice Agent 
 
Page 13 of 27 
 
3. Each chunk is embedded via OpenAI text-embedding-3-small and then stored in a 
Chroma vector database with metadata (date, category, amount, file source) 
4. The agent running the query retrieves the top-k most relevant chunks of financial 
information based on the cosine similarity 
5. These chunks are then used to inject prompts into the LLM prompt context

6. Project Description 
AI-Powered SME Financial Advisory System is a web -based software that acts like a smart, 
real-time financial consultant for SMEs. An SME business owner accesses the web -based 
application, and starts conversing with the software either through typing in the chat box or by 
pressing the microphone icon to speak. 
6.1 User Journey 
1. Owner uploads last month's bank statement (CSV from internet banking) or P&L 
spreadsheet (Excel) 
2. Document Parser Agent processes the file within seconds, extracting categories, 
totals, and trends 
3. Owner asks by voice or text “Did I make a profit last month?" or "Where am I 
overspending?" 
4. The system responds with a clear, conversational answer grounded in the uploaded 
data 
5. Owner asks a forward-looking question: "Can I afford a LKR 2 million equipment 
loan next quarter?" 
6. Cash Flow Forecast Agent runs a 90-day projection and gives a clear yes/no with 
supporting analysis 
7. At month end, the Report Generator Agent automatically prepares a one-page 
financial health summary as a downloadable PDF

6.2 Core Modules 
6.2.1 Voice + Chat Interface 
React.js-based web application that has a dual -purpose interface: text chat (always enabled) 
and voice mode (voice button). When the voice mode is activated, the user utters the query, 
which is answered in two ways – first, via the text displayed on the sc reen, and second, via 
text-to-speech functionality. This web application can run on the smartphone browser, which 
is used by most SME owners in Sri Lanka. 
6.2.2 Financial Data Upload and Analysis 
Users upload Excel or CSV files through a simple drag -and-drop interface. The Document 
Parser Agent supports multiple file formats including bank statement CSVs from major Sri 
Lankan banks (BOC, Sampath, HNB, Commercial Bank), standard P&L Excel templates, and 
inventory cost sheets. The system automatically identifies and categorises financial data 
without requiring any manual formatting from the user. 
6.2.3 Cash Flow Forecasting 
The Cash Flow Forecasting Agent, utilizing historical data from uploads, generates a cash flow 
forecast for 30, 60, and 90 days into the future based on time series pattern recognition and 
context-based adjustments by an LLM. The reasoning about future exp enses (rent, salaries, 
loan payments) and income (seasonal effects, outstanding bills) is explicit. 
6.2.4 Investment and Market Intelligence 
Market Research Agent collects real -time information about financial markets from Yahoo 
Finance (international equities, gold, USD/LKR foreign exchange), Colombo Stock Exchange 
(CSE best-performers, dividend information), and publications of Central Bank o f Sri Lanka 
(policy interest rates, inflation rate). Investment Advisor Agent utilizes this information along 
with cash holdings of SMEs in order to advise suitable investment for excess cash funds either 
FDs, T-Bills, or shares at CSE blue chip companies. 
6.2.5 Monthly Financial Health Report 
Report Generator Agent produces an informative one -to-two-page PDF report containing a 
graphical representation of income vs. expenses (using Matplotlib), the top 5 items that 
constitute expenses, the path that cash flow is on via a graph, the performance of the 
investments, and three practical suggestions for the next month.

9. Limitations 
 
The following limitations are acknowledged and will be clearly documented in the final 
dissertation. They do not undermine the academic or practical value of the project but define 
its appropriate scope of use. 
9.1 Regulatory Limitation 
This tool offers decision -making data and financial analysis training. This is not regulated 
financial advice under the Securities and Exchange Commission of Sri Lanka Act and the 
Banking Act. There will be an obligatory warning in the software that clarifies this point to all 
users. The system should not be relied on as the sole source for important financial decisions 
without seeking professional help.

9.2 Voice Recognition Accuracy 
While OpenAI Whisper has strong multilingual capability, its accuracy on heavily accented Sri 
Lankan English or dense Sinhala -English code-mixed speech may be lower than on standard 
English.  
9.3 Data Format Dependencies 
The Document Parser Agent is designed to work with typical CSV and Excel files from some 
leading banks in Sri Lanka, as well as accounting forms. Nevertheless, it might not be able to 
work properly with files that have unusual structures, passwords, or con sist solely of scans. 
The user will be informed of this failure and shown how to format the document appropriately. 
PDF invoice parsing with tabula-py operates better on digital files. 
9.4 LLM Hallucination Risk 
While the RAG pipeline ensures that the response is grounded in actual data uploaded by users, 
Large Language Models might still produce some statements that are believable but not 
necessarily true, especially when projecting future finances involving many  steps. A special 
layer that does fact -checking will cross -reference the numbers against the raw data before 
presenting it to the user. 
9.5 Scope Boundaries 
• “Tax calculation and tax return preparation” is not a part of MVP - the MVP system 
will have generic advice on taxation but will not generate calculated tax returns 
• Brokerage accounts integration as well as API for banks is not considered within 
MVP scope because there are no publicly available broker APIs from Sri Lanka 
• The system is optimized for small - and medium-sized businesses; it is not meant 
for large corporations with complicated multi-entity accounting
